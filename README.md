# What's Pouring? 🍸

A mobile-first personal cocktail recommendation and home-bar inventory app built around Brendan's actual bar and cocktail preferences.

## V1

- Preloaded home-bar inventory
- Dealer's Choice or spirit-based recommendations
- Mood filters: spirit-forward, refreshing, citrusy, bitter, cozy
- Make It Now
- Almost There (one ingredient away)
- Distinguishes easy grocery pickups from specialty bottles
- Add bottles/ingredients and mark items out of stock
- Ratings and Favorites
- Browser `localStorage` persistence for inventory and ratings
- Mobile-first design

## Run it

This version is intentionally dependency-free. Open `index.html` in a browser or deploy the repository as a static site.

## Product direction

V2 can expand the recipe library, improve ingredient matching, add an Expand My Bar / What Should I Buy Next engine, add running-low status, and optionally sync inventory across devices.
